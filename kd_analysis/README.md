# Ανάλυση Kd (συγγένεια TIP–TetR)

Συμπληρωματική δουλειά πάνω στην παράμετρο `Kd_TIP_TetR`, η οποία στην
ανάλυση ευαισθησίας v4 κατατάσσεται ως **μη περιορισμένη**: καμία πηγή,
καμία μέτρηση. Το TIP είναι νέο μόριο.

## Σχέση με το `python/`

Ο φάκελος `python/` είναι **παγωμένος**. Η ανάλυση ευαισθησίας v4 έχει
ολοκληρωθεί και τα αποτελέσματά της αναπαράγονται bit-προς-bit. Κανένα
script εδώ δεν τροποποιεί αρχείο εκεί — τα scripts του `modeling/`
κάνουν `import` τη μηχανή προσομοίωσης και ορίζουν δικά τους πλέγματα.

## Γιατί χρειάζεται επέκταση πλέγματος

Το sweep του v4 καλύπτει Kd από 0.0025 έως 25 nM (×0.01 έως ×100 του
baseline 0.25 nM). Οι δομικές εκτιμήσεις (ClusPro/PRODIGY, HPEPDOCK,
AlphaFold3) τοποθετούν το Kd στην περιοχή 62–4500 nM, δηλαδή **εκτός
του σαρωμένου πλέγματος**. Χωρίς επέκταση δεν μπορούμε να πούμε τι
συμβαίνει στο εύρος που πραγματικά μας αφορά.

## Περιεχόμενα

- `modeling/` — προσομοιώσεις πάνω στο SBML μοντέλο
- `results/` — έξοδοι CSV (δεν εκδίδονται στο git αν είναι μεγάλα)
