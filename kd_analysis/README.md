# Ανάλυση Kd (συγγένεια TIP–TetR)

Συμπληρωματική δουλειά πάνω στην παράμετρο `Kd_TIP_TetR`, η οποία στην ανάλυση
ευαισθησίας v4 κατατάσσεται ως **μη περιορισμένη**: καμία πηγή, καμία μέτρηση.

**Πλήρης καταγραφή:** [`KD_ANALYSIS_REPORT.md`](KD_ANALYSIS_REPORT.md)

---

## Αποτέλεσμα

| | |
|---|---|
| Εκτίμηση Kd | **3.7 – 8.1 nM** (PDB 2NS8, δύο ανεξάρτητα αντίγραφα) |
| 90% CI | 0.1 – 327 nM, εξ ολοκλήρου από τη βαθμονόμηση PRODIGY |
| Απαίτηση κυκλώματος | Kd κάτω από το όριο ανίχνευσης· ο tandem timer δεν περιορίζει |
| P(λειτουργικό), LOD 1.2x | 67.6% |
| P(λειτουργικό), LOD 1.5x | ~50% |

**Επόμενο βήμα:** μέτρηση του πραγματικού LOD του μικροσκοπίου από το αρνητικό
control — αλλάζει το συμπέρασμα κατά 18 ποσοστιαίες μονάδες και δεν κοστίζει
νέο πείραμα.

---

## Σχέση με το `python/`

Ο φάκελος `python/` είναι **παγωμένος**. Η ανάλυση ευαισθησίας v4 έχει
ολοκληρωθεί και τα αποτελέσματά της αναπαράγονται bit-προς-bit. Κανένα script
εδώ δεν τροποποιεί αρχείο εκεί — το `run_kd_extended.py` κάνει `import` τη
μηχανή προσομοίωσης (κλάση `Variant`) και ορίζει μόνο δικό του πλέγμα.

## Δομή

```
modeling/
  run_kd_extended.py    επέκταση πλέγματος Kd (0.0025 – 5000 nM)
  kd_window.py          λειτουργικό παράθυρο: ανιχνευσιμότητα + timer
  kd_montecarlo.py      διάδοση αβεβαιότητας -> πιθανότητα λειτουργίας
  kd_bayesian.py        σύνθεση δομικού prior + πειραματικού likelihood

  2NS8_full.pdb         πειραματική δομή TetR–Tip
  2NS8_ABH.pdb          διμερές A+B + πεπτίδιο H
  2NS8_CDF.pdb          διμερές C+D + πεπτίδιο F

```

## Εκτέλεση

```bash
cd modeling

# 1. προσομοίωση (αργό, γράφει results/kd_extended.csv)
python run_kd_extended.py

# 2. λειτουργικό παράθυρο
python kd_window.py --fold 1.5 --ratio 0.20

# 3. πιθανότητα λειτουργίας
python kd_montecarlo.py --fold 1.5 --ratio 0.20

# 4. prior μόνο (χωρίς πειραματικά δεδομένα)
python kd_bayesian.py

# 4b. μετά το Exp.2
python kd_bayesian.py --variant ox --fold-obs 1.8 --fold-sd 0.15
```

**Παράμετροι που πρέπει να τεκμηριωθούν πριν χρησιμοποιηθούν:**

- `--fold` — το όριο ανίχνευσης του οργάνου. Προεπιλογή 1.5 (γενική τιμή για
  μικροσκοπία, **όχι μετρημένη**). Μόλις υπάρχουν δεδομένα από αρνητικά
  controls: `LOD = (mean_bg + 3·SD_bg) / mean_bg`.
- `--ratio` — κατώφλι διασποράς λόγου. **Χρησιμοποιήστε 0.20**, όχι την
  προεπιλογή 0.05. Κατά το `ichnos_invariance.py`, το 0.05 σημαίνει «τέλεια
  αμεταβλητότητα» ενώ το 0.20 είναι το όριο πέρα από το οποίο ο λόγος παύει να
  λειτουργεί ως ρολόι.

## Δύο αναθεωρήσεις κατά την πορεία

Το συμπέρασμα άλλαξε δύο φορές. Και οι δύο αλλαγές τεκμηριώνονται πλήρως στην
αναφορά, επειδή είναι από μόνες τους μεθοδολογικά αποτελέσματα.

**1. Η θέση δέσμευσης εκτείνεται πάνω από το διμερές TetR** (§4). Όλα τα
docking έγιναν εναντίον μονομερούς — έλειπε η μισή θέση δέσμευσης. Ελεγχόμενο
πείραμα στην ίδια πειραματική δομή: διμερές −11.2 kcal/mol, μονομερές −8.3.
Διαφορά **2.9 kcal/mol, δηλαδή 117x στο Kd**.

**2. Το κατώφλι διασποράς 0.05 δεν ήταν κριτήριο λειτουργίας** (§5). Το
πραγματικό όριο είναι 0.20. Η μέγιστη διασπορά σε όλο το πλέγμα είναι 0.0815,
άρα ο timer δεν περιορίζει τίποτα.

| | Διάμεσος Kd | P(λειτουργικό), 1.5x |
|---|---|---|
| Αρχικά | 360 nM | 2.4% |
| Μετά τη διόρθωση διμερούς | 6 nM | 9.5% |
| Μετά τη διόρθωση κατωφλίου | 6 nM | **~50%** |
